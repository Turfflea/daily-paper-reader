## 摘要
构建图基础模型的一个核心障碍是输入在特征空间维度、语义和结构方面的异质性。这种异质性限制了图神经网络泛化到具有未见特征空间的新图的能力。我们通过 SIGIL 框架应对这一可迁移性挑战，该框架将任意带属性图映射到固定维度的统一表示空间。给定一个图，SIGIL 将其提升为一个结构交互图，其中节点是输入特征维度，带权、带类型的边编码该图多阶连通性上的特征对齐。关系消息传递网络将每个特征维度嵌入到共享空间中，将任意维度的原始节点特征转换为可迁移到任何下游图的表示。在构造上，SIGIL 对节点、特征维度和标签的置换具有等变性。此外，当输入特征是离散关系的独热指示符时，SIGIL 恢复并严格推广了现有的知识图谱推理基础模型。在单个图上预训练的单一 SIGIL 模型可实现强大的全归纳链接预测。同时，SIGIL 可用于实现现有的知识图谱基础模型。因此，SIGIL 在统一框架下统一了图基础模型设计中的若干现有范式。

## Abstract
A central obstacle in building graph foundation models is the input heterogeneity in terms of feature space dimensionality, semantics, and structure. Such heterogeneity limits the capability of graph neural networks to generalize to new graphs with unseen feature spaces. We address the transferability challenge with SIGIL, a framework that maps any attributed graph to a unified representation space of fixed dimension. Given a graph, SIGIL lifts it to a structural interaction graph, where nodes are the input feature dimensions and weighted, typed edges encode feature alignment across multiple orders of the graph's connectivity. A relational message-passing network embeds each feature dimension into a shared space, transforming the original node features, of arbitrary dimensionality, into representations transferable to any downstream graph. By construction, SIGIL is equivariant to permutations of nodes, feature dimensions, and labels. Additionally, when the input features are one-hot indicators of discrete relations, SIGIL recovers and strictly generalizes existing foundation models for knowledge graph reasoning. A single SIGIL model, pretrained on one graph, delivers strong fully-inductive link prediction. Also, SIGIL can be used to implement existing knowledge graph foundation models. As such, SIGIL unifies several existing regimes in graph foundation model design under a single framework

## 1. 论文的核心问题与整体含义

- **研究背景**：图基础模型（Graph Foundation Models, GFMs）的目标是让模型在未见过的图、特征空间和标签空间上执行推理，而无需针对特定任务重新训练。
- **核心障碍**：图数据输入存在高度异质性——节点特征维度不同、各坐标语义不同、图结构不同、标签集合不同。这导致在一个图上训练的 GNN 通常无法直接读取另一个图。
- **现有两条路线**：
  - 面向任意图节点分类的模型（如 GraphAny、TS-MEAN、TAG、RGVT）：能处理任意特征和标签空间，但主要针对节点分类，难以扩展到链接预测或关系推理。
  - 知识图谱基础模型（KGFMs，如 ULTRA、TRIX、InGRAM）：通过“关系图”实现零样本迁移，但本质上只支持离散关系类型，无法处理连续节点/边特征。
- **本文整体含义**：提出 SIGIL 框架，将任意带属性图提升为“结构交互图（SIG）”，在该图上学习特征维度的可迁移表示，从而统一上述两条路线。SIGIL 既支持连续特征空间，又能严格推广离散关系场景下的 KGFM，并同时适用于链接预测和节点分类。

## 2. 论文提出的方法论

### 2.1 核心思想
- 给定图 \(G=(V,E)\) 和节点特征 \(X\in \mathbb{R}^{n\times d}\)，SIGIL 不直接在原图上学习，而是构造一个以**特征维度为节点**的新图——结构交互图（Structural Interaction Graph, SIG）。
- SIG 的边表示不同特征维度在图的多阶连通性上的对齐程度，即两个特征在图结构中的共现/交互模式。
- 在 SIG 上运行关系消息传递网络，将每个特征维度嵌入到固定大小的共享空间，然后用该嵌入将原始节点特征映射到统一维度，供下游任务使用。

### 2.2 关键技术步骤
1. **多阶特征传播**：  
   对每个阶 \(k\)，计算 \(X^{(k)} = A^k X\)，其中 \(A\) 为邻接矩阵，得到图结构上 \(k\) 阶邻域聚合后的特征矩阵。

2. **边特征提取**：  
   对每条边 \((i,j)\in E\)，用交互算子 \(g\) 计算边特征  
   \[
   x^{(k)}_{ij} = g(X^{(k)}_{i,:}, X^{(k)}_{j,:})
   \]  
   其中 \(g\) 可取绝对差、逐元素乘积等。

3. **节点级角色聚合**：  
   对每个节点 \(i\)，聚合其所有入边/出边上的边特征，得到节点摘要  
   \[
   \bar X^{(k)}_{i,:} = \frac{1}{|N_i|}\sum_{j\in N_i} x^{(k)}_{ij}
   \]  
   有向图则分别按头/尾角色聚合，得到 \(\bar X^{(k)}_h\) 和 \(\bar X^{(k)}_t\)。

4. **特征维度交互矩阵（Gram 矩阵）**：  
   对每一阶 \(k\)，计算  
   \[
   \bar A^{(k)} = (\bar X^{(k)})^\top \bar X^{(k)} \in \mathbb{R}^{d\times d}
   \]  
   其元素 \((\bar A^{(k)})_{f,f'}\) 衡量特征 \(f\) 和 \(f'\) 在该阶邻域模式上的对齐程度。对于有向图，进一步计算四个角色交叉矩阵（hh、tt、ht、th）。

5. **堆叠为 SIG**：  
   将各阶、各角色通道的 \(\bar A^{(k)}\) 堆叠，得到带类型、带权重的结构交互图 \(G_{\text{struct}}\in \mathbb{R}^{d\times d\times R}\)，其中 \(R\) 为边类型数（无向图为 \(K+1\)，有向图为 \(4(K+1)\)）。

6. **SIG 上的关系消息传递**：  
   在 \(G_{\text{struct}}\) 上运行关系 MPNN（如 RGCN 风格），更新特征维度嵌入 \(\Theta^{(t)}\)：  
   \[
   \Theta^{(t+1)} = \Theta^{(t)} W_{\text{self}} + \sum_{k=0}^{K} \bar A^{(k)} \Theta^{(t)} W_k
   \]  
   其中 \(W_*\) 的参数只作用于固定隐藏宽度 \(d_h\)，与输入特征维度 \(d\) 无关。最终得到 \(\Theta^{(T)}\in \mathbb{R}^{d\times d_h}\)。

7. **生成统一节点表示**：  
   通过 \(H = X \Theta^{(T)}\) 将任意维度 \(d\) 的节点特征映射到固定维度 \(d_h\)。还可以生成多视图表示 \(H^{(k)} = X^{(k)}\Theta^{(T)}\) 供下游使用。

### 2.3 理论性质
- **严格推广 KGFM**：当输入特征是离散关系的 one-hot 指示符时，SIG 构造恰好恢复 ULTRA 等 KGFM 的“关系图”，因此 SIGIL 是 KGFM 从离散到连续、从单阶到多阶的严格推广（Theorem 1）。
- **对称性**：SIG 对节点置换不变、对特征置换等变；Sigil 输出的节点表示对节点置换等变、对特征置换不变；配合等变解码器可支持标签置换（Lemma 1, Proposition 1）。

## 3. 实验设计

### 3.1 链接预测（Sigil-lp）
- **数据集**：11 个基准，分为两组：

  - 4 个非属性图：C.ele、USAir、PB、NS；非属性图通过 DeepWalk 在训练边上初始化特征。
- **对比方法**：
  - 全归纳基线：UniLP、TFMLinker。
  - 转导基线（作为参考）：NBFNet、ELPH、NCNC、MPLP+。
- **训练与评估**：Sigil-lp 仅在 Cora 上预训练，零样本应用到所有目标图；评价指标为 Hits@100（引文网络）或 Hits@50（其余）。

### 3.2 知识图谱推理（实现 KGFM）
- **数据集**：3 个预训练图（FB15k-237、WN18RR、CoDEx-Medium）；ULTRA 协议下的 23 个 inductive (e,r) 图（未见实体和关系）和 18 个 inductive (e) 图（未见实体）。

- **变体**：Sigil(0)、Sigil(1)、Sigil(2)，分别对应 SIG 阶数 \(K=0,1,2\)。

### 3.3 节点分类（Sigil-nc）

- **训练与评估**：Sigil-nc 仅在 Cora 上预训练，对每个目标图零样本生成节点表示，然后拟合轻量 MLP 映射到下游标签空间。

## 6. 论文的主要结论与发现

- **统一框架**：SIGIL 通过结构交互图将任意维度特征映射到固定维度表示，同时支持链接预测和节点分类，统一了图基础模型设计中的多条路线。
- **严格推广 KGFM**：当输入为 one-hot 关系指示时，SIG 恢复 ULTRA 的关系图；实验上 Sigil(0) 能复现 ULTRA 的 MRR 和 Hits@10，误差在约 2 个点以内。
