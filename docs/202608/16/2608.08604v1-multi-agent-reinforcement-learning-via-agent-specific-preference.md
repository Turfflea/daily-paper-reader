## 摘要
多智能体强化学习（MARL）是解决复杂协作任务的强大框架，但它高度依赖于定义良好的全局奖励函数。设计此类奖励具有挑战性，尤其是在具有异质智能体的系统中，单一标量目标可能无法刻画多样化的行为。本文提出了多智能体偏好集成学习（MAGPIE），通过智能体特定偏好建模来应对这些挑战。每个智能体由专门的专家通过偏好信号进行评估，从而无需全局评估。我们从理论上证明，优化这些去中心化偏好会收敛到纳什均衡策略。为了将局部偏好整合为一致的全局目标，我们从偏好数据中构建智能体特定的奖励模型，并通过单调聚合机制将其组合。我们进一步证明，优化该聚合奖励模型等价于训练纳什均衡策略。在基准多智能体任务和顺序生产线任务上的大量实验表明，MAGPIE 取得了与经过奖励工程设计的基线相当的性能，展示了其在精确奖励工程不切实际的场景中促进策略学习的潜力。

## Abstract
Multi-agent reinforcement learning (MARL) is a powerful framework for solving complex collaborative tasks, but it relies heavily on well-defined global reward functions. Designing such rewards is challenging, especially in systems with heterogeneous agents, where a single scalar objective may fail to capture diverse behaviors. In this paper, we introduce Multi-AGent Preference-Integrated lEarning (MAGPIE), which addresses these challenges through agent-specific preference modeling. Each agent is evaluated by a dedicated expert through preference signals, eliminating the need for global evaluation. We theoretically prove that optimizing these decentralized preferences converges to a Nash equilibrium policy. To integrate local preferences into a coherent global objective, we construct agent-specific reward models from preference data and combine them via a monotonic aggregation mechanism. We further prove that optimizing this aggregate reward model is equivalent to training the Nash equilibrium policy. Extensive experiments on benchmark multi-agent tasks and a sequential production line task show that MAGPIE achieves performance comparable to reward-engineered baselines, demonstrating its potential to facilitate policy learning in scenarios where precise reward engineering is impractical.

## 2. 论文提出的方法论

- **核心思想**  
  为每个智能体分配一个专门的“教师”（或专家），由该教师仅针对该智能体的行为提供偏好信号（例如比较两个轨迹片段哪个更好），避免了对整个团队行为的复杂全局评估。  
  然后从这些智能体特定的偏好数据中学习局部奖励模型，再通过单调聚合（加和）得到全局奖励，供标准 MARL 算法使用。

- **理论框架与关键假设**  
  - **假设 1–2**：每个智能体存在定义良好的偏好关系，满足对称性、一致性、传递性；且每个智能体都有可靠的教师提供偏好反馈。  
  - **假设 3**：存在有界的真实全局奖励函数 \(r(s, \mathbf{A})\)。  
  - **假设 4**：智能体局部偏好与全局回报一致，即局部偏好的改进严格对应全局回报提升。  
  - **假设 5**：每个智能体存在隐式局部奖励函数 \(r_i(s, \mathbf{A})\)，其偏好与局部回报一致。  
  - **假设 6**：真实全局奖励可表示为局部奖励的函数 \(F(r_1,\dots,r_n)\)，且 \(F\) 连续可微。  
  - **假设 7**：任何智能体的局部改进不会导致其他智能体局部回报之和的下降幅度超过自身改进幅度，保证加和聚合不降低全局回报。

- **主要定理**  
  - **定理 1**：在有限状态/动作空间、无限段长度 \(H\to\infty\) 的理想条件下，基于局部偏好迭代更新每个智能体策略（算法 1）最终收敛到纳什均衡联合策略。  
  - **定理 2**：若学习到的局部奖励模型与教师偏好完全一致，则最大化加和全局奖励 \(\hat{r} = \sum_i \hat{r}_i\) 的联合策略构成真实全局奖励下的纳什均衡。  
  - **定理 3**：在偏好数据覆盖充分时，最小化交叉熵损失可使局部奖励模型收敛到真实局部奖励的仿射变换，并给出有限样本下的 \(O(1/\sqrt{N})\) 误差界。  
  - **定理 4**：有限偏好样本下，基于学习到的聚合奖励得到的策略是 \(\epsilon\)-纳什均衡，其中 \(\epsilon = \frac{2n\epsilon_r(N)}{1-\gamma}\)，随样本量增大趋于零。

- **实用算法（MAGPIE，算法 2）**  
  1. **偏好建模**：对每个智能体 \(i\)，使用 Bradley-Terry 模型定义偏好概率  
     \[
     P_\psi[\sigma^{(1)} \succ_i \sigma^{(0)}] = \frac{\exp\left(\sum_t \gamma^t \hat{r}_i^\psi(s_t^{(1)}, \mathbf{A}_t^{(1)})\right)}{\sum_{j\in\{0,1\}} \exp\left(\sum_t \gamma^t \hat{r}_i^\psi(s_t^{(j)}, \mathbf{A}_t^{(j)})\right)}
     \]
     并最小化交叉熵损失训练奖励模型。  
  2. **正则化**：引入辅助损失 \(L_i^{reg}\)，惩罚“局部偏好段却导致全局估计回报下降”的情况，以支持假设 7。  
  3. **单调聚合**：将局部奖励模型加和得到全局奖励 \(\hat{r}(s,\mathbf{A}) = \sum_{i=1}^n \hat{r}_i^\psi(s,\mathbf{A})\)。  
  4. **与 MARL 集成**：用学习到的全局奖励替代环境奖励，采用 QMIX 进行策略优化；同时使用连续偏好收集和经验重标记技术提高样本效率。

## 3. 实验设计

- **基准任务**  
  - **MPE 多智能体粒子环境**：  
    - Simple-Spread：3 个同质智能体覆盖地标，测试信用分配。  
    - Simple-Speaker-Listener：异构角色（说话者与听者），测试角色差异下的偏好整合。  
    - Simple-Reference：非对称部分可观测，两个智能体需合作到达各自目标。  
  - **自定义顺序手机生产线任务**：  
    - 模拟 SMT、组装、测试三阶段生产线，每个阶段由一个智能体控制；状态包含各阶段缓冲容量与占用，动作包含低/中/高三档处理速度；奖励由任务完成数、缓冲溢出惩罚和能耗惩罚组成。

- **对比方法**  
  - **奖励工程 oracle**：QMIX with true task reward、MATD3 with true task reward。  
  - **偏好驱动 baselines**：Global-PbRL（学习单一全局奖励模型）、MAPT。  
  - **消融实验**：移除偏好模块、移除正则化项、将加和聚合替换为乘性聚合、移除经验重标记、移除连续偏好收集。

- **实验设置**  
  - 偏好信号由基于角色的启发式规则自动生成，而非真实人类标注。  
  - 段长度 \(H\) 在 MPE 任务中取 3、5、10；在生产线任务中取 5、10、20。  
  - 还测试了 Simple-Spread 任务上智能体数量从 3 扩展到 6 的可扩展性。  
  - 所有结果在 5 个随机种子下报告均值与标准误差。

## 6. 论文的主要结论与发现

- MAGPIE 在三个 MPE 基准任务和自定义生产线任务上，仅使用去中心化、角色特定的偏好信号，就能达到与使用真实奖励的 QMIX oracle 相当的性能。
- 在异构显著的 Simple-Speaker-Listener 任务中，MAGPIE 学习曲线几乎与 oracle 重合，验证了其对异构智能体的支持能力。
- 对不同段长度 \(H\)（3/5/10/20）表现稳健，说明方法不需要精确的时序粒度调参。
- 在智能体数量扩展至 6 时，MAGPIE 仍保持与 oracle 相当的性能，表明其可扩展性。
- 消融实验表明：偏好学习模块、单调聚合、经验重标记和连续偏好收集都是成功的关键；正则化项虽非必需，但可提升训练后期稳定性。
- 奖励热力图可视化显示，各智能体的局部奖励模型能捕捉到“靠近未被占据地标”等直观模式，证明所学奖励的合理性。

## 7. 优点

- **实验设计全面**：包含多个基准任务、多种段长度、对比方法、消融研究和可扩展性测试，验证较为充分。
