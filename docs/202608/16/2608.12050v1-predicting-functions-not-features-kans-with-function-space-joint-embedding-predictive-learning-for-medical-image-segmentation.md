## 摘要
柯尔莫哥洛夫-阿诺德网络（KANs）通过将每条网络边参数化为可学习的单变量函数，引入了显式的函数表示。然而，现有的基于KAN的分割模型仅通过边聚合之后定义的目标来优化边函数，导致单个函数在聚合前缺乏明确的学习目标。为了解决这一局限性，我们提出了用于医学图像分割的函数空间联合嵌入预测学习（FS-JEPA）。我们的FS-JEPA框架将预测学习引入KAN的聚合前函数空间。一个掩码在线分支预测由全上下文指数移动平均目标分支生成的采样KAN边函数的结构化签名，而共享的边索引则保持预测与目标之间的对应关系。我们不预测孤立的边响应，而是使用多半径签名来表示每个采样的边函数，该签名由围绕其输入锚点的函数评估组成。这种结构化表示捕获了单个响应无法表征的局部函数变化，并提供了更具信息量的预测目标。在训练期间，函数空间目标与分割损失联合优化，而在推理时移除预测分支。在五个医学图像分割基准上的实验表明，我们的FS-JEPA取得了最佳平均Dice系数，并比最强的基于KAN的竞争方法高出+2.25个百分点。

## Abstract
Kolmogorov--Arnold Networks (KANs) introduce explicit functional representations by parameterizing each network edge as a learnable univariate function. However, existing KAN-based segmentation models optimize edge functions only through objectives defined after edge aggregation, leaving individual functions without an explicit pre-aggregation learning target. To address this limitation, we propose Function-Space Joint-Embedding Predictive Learning (FS-JEPA) for medical image segmentation. Our FS-JEPA framework moves predictive learning into the pre-aggregation function space of KANs. A masked online branch predicts structured signatures of sampled KAN edge functions generated by a full-context exponential moving average target branch, while shared edge indices preserve correspondence between predictions and targets. Rather than predicting an isolated edge response, we represent each sampled edge function using a multi-radius signature composed of function evaluations around its input anchor. This structured representation captures local functional variations that cannot be characterized by a single response and provides a more informative predictive target. The function-space objective is jointly optimized with the segmentation loss during training, while the predictive branch is removed at inference. Experiments on five medical image segmentation benchmarks show that our FS-JEPA achieves the best average Dice and outperforms the strongest competing KAN-based method by +2.25 percentage points.

## 1. 论文的核心问题与整体含义

- **研究背景**：医学图像分割面临弱对比、边界模糊、伪影、外观变化大等挑战。现有编码器-解码器网络（如U-Net系列）的非线性变换主要由固定激活和标量权重隐式定义，缺乏显式函数对象。
- **KAN的引入与局限**：Kolmogorov–Arnold Networks（KANs）将每条网络边参数化为可学习的单变量函数，提供了显式函数表示。U-KAN、KAT等工作已将KAN引入医学分割或视觉任务。
- **核心问题**：现有KAN分割模型仅在**边聚合之后**定义损失，即只约束聚合后的节点输出，导致不同边函数配置可能产生相近的节点输出（多对一映射），单个边函数在**聚合前缺乏明确学习目标**。
- **研究动机**：联合嵌入预测学习（JEPA）擅长学习结构化表示，但现有JEPA方法只停留在图像、token或特征层面，没有把可学习神经函数本身作为预测目标。
- **整体含义**：提出 **FS-JEPA（Function-Space Joint-Embedding Predictive Learning）**，将JEPA预测学习扩展到KAN的预聚合函数空间，直接对单个边函数的局部函数行为进行表征学习，从而提升医学图像分割性能。

## 2. 论文提出的方法论

- **总体框架**：
  - 在U型KAN分割网络的KAN块上附加一个**训练专用的函数空间JEPA分支**。
  - 在线分支接收带掩码的token序列，预测由全上下文EMA目标分支生成的边函数签名。
  - 在线分支与目标分支共享相同的采样边索引，保证预测与目标的边级对应。
  - 预测目标位于**KAN边聚合之前**，直接针对单个边函数 \(\phi_{j,i}\)。
  - 推理时移除所有预测组件，保持原分割网络不变。

- **KAN边函数与边采样**：
  - 边函数采用样条参数化：基础函数项 + 可学习样条尺度 + B样条基函数的加权和。
  - 标准KAN前向聚合 \(y_j = \sum_i \phi_{j,i}(x_i)\) 造成多对一映射，难以监督单个边函数。
  - 为避免直接计算所有边的响应（复杂度 \(O(BNd_\text{in}d_\text{out})\)），随机采样 \(K\) 个输入-输出边对，通过**选择边算子**只评估采样的边函数，将辅助激活成本降至 \(O(BNK)\)。

- **多半径边函数签名**：
  - 单点响应无法充分表征函数局部行为，两个不同函数可能在同一点响应相同但邻域表现不同。
  - 对每个采样边 \((i,j)\)，围绕输入锚点 \(u\) 定义一组局部偏移：
    \[
    D = \{-0.10,-0.05,-0.025,0.025,0.05,0.10\}
    \]
  - 函数签名由这些邻域点的函数评估组成：
    \[
    s_e = [\phi_e(u-0.10), \phi_e(u-0.05), \phi_e(u-0.025), \phi_e(u+0.025), \phi_e(u+0.05), \phi_e(u+0.10)]
    \]
  - 这种多半径签名捕获了输入锚点附近的局部函数变化，提供了比单响应更丰富的预测目标。

- **确定性边对应**：
  - 随机采样边可能导致跨迭代的位置对应不一致。
  - 对每个采样边 \((i,j)\)，用确定性坐标编码其源节点和目标节点位置：
    \[
    p_i = \frac{2(i-1)}{d_\text{in}-1} - 1, \quad p_j = \frac{2(j-1)}{d_\text{out}-1} - 1
    \]
  - 坐标对 \((p_i, p_j)\) 与函数签名拼接，作为签名预测器的条件，在在线和目标分支之间建立一致对应，无需额外可学习参数。

- **函数签名预测目标**：
  - 在线预测器接收掩码上下文表示 + 边响应 + 输入锚点 + 确定性坐标，输出预测签名 \(\hat{s}_e\)。
  - 目标分支通过指数移动平均（EMA）生成目标签名 \(s_e^+\)，并施加stop-gradient。
  - 预测损失采用 Smooth L1：
    \[
    L_\text{sig} = \text{SmoothL1}(\hat{s}_e, s_e^+)
    \]
  - 该目标直接约束预聚合边函数，不需要对比负样本、重建损失或手工导数约束。

- **联合优化与推理**：
  - 分割目标包含主分割损失 \(L_\text{seg}\) 和解码器侧深度监督损失 \(L_\text{deep}\)。
  - 四个KAN块配备预测分支，最终训练目标：
    \[
    L_\text{total} = L_\text{seg} + \lambda_\text{deep} L_\text{deep} + \lambda_\text{sig} \frac{1}{4}\sum_{b=1}^{4} L_\text{sig}^{(b)}
    \]
  - 从随机初始化联合训练，不使用预训练权重或外部教师模型；推理时预测分支被移除。
