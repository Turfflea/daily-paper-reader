## 摘要
无监督时间序列域适应（DA）解决在由不同用户、传感器、设备、采集条件或时间动态引起的分布偏移下，将分类器从有标签源域迁移到无标签目标域的挑战。现有方法通常通过对抗训练、最优传输或基于矩的差异来对齐边缘特征分布，从而缓解这种偏移。本文提出类条件路径分布对齐（CPDA），一种基于差异的非对抗框架，该框架对齐源域和目标域的类条件潜在路径分布，而不仅仅是全局特征边缘分布。CPDA 引入了一种复合签名-谱核，联合捕获池化语义特征、时间路径结构、频域信息和低秩路径签名动态，同时利用源标签和目标软伪标签执行保类对齐。我们进一步提供了理论分析，表明 CPDA 定义了一个有效的核差异，将现有矩匹配方法视为其受限特例，并给出了类条件目标风险界。在 13 个不同的时间序列 DA 基准上，使用 CNN、ResNet18 和 TCN 骨干网络进行的大量实验表明，CPDA 相对于 30 种差异、对抗和伪标签基线方法具有有效性。

## Abstract
Unsupervised time-series domain adaptation (DA) addresses the challenge of transferring a classifier from a labeled source domain to an unlabeled target domain under distribution shifts induced by different users, sensors, devices, acquisition conditions, or temporal dynamics. Existing methods typically mitigate this shift by aligning marginal feature distributions through adversarial training, optimal transport, or moment-based discrepancies. In this paper, we propose Class-Conditional Path Distribution Alignment (CPDA), a non-adversarial discrepancy-based framework that aligns source and target class-conditional latent path distributions rather than only global feature marginals. CPDA introduces a composite signature-spectral kernel that jointly captures pooled semantic features, temporal path structure, frequency-domain information, and low-rank path-signature dynamics, while using source labels and target soft pseudo-labels to perform class-preserving alignment. We further provide a theoretical analysis showing that CPDA defines a valid kernel discrepancy, admits existing moment-matching methods as restricted cases, and yields a class-conditional target-risk bound. Extensive experiments with CNN, ResNet18, and TCN backbones on 13 different time-series DA benchmarks demonstrate the effectiveness of CPDA against 30 discrepancy, adversarial, and pseudo-labeling baselines.

## 1. 论文的核心问题与整体含义

- 论文研究**无监督时间序列域适应（Unsupervised Domain Adaptation, UDA）**：给定有标签源域和无标签目标域，目标是在用户、传感器、设备、采集条件或时间动态导致的分布偏移下，将分类器迁移到目标域。
- 现有方法主要通过对抗训练、最优传输或矩匹配来对齐**边缘特征分布**，但存在三类问题：
  - 边缘对齐可能忽略类别结构，导致不同类样本被错误匹配；
  - 常见特征级差异将表示视为无序向量，丢失时间顺序和动态演化信息；
  - 低阶矩匹配难以刻画非高斯、动态和频率相关差异。
- 论文提出 **CPDA（Class-Conditional Path Distribution Alignment）**，将对齐对象从全局特征边缘提升到**类条件潜在路径分布**，并引入复合签名–谱核来同时捕捉语义、时间路径、频域和路径签名信息。

## 2. 方法论

### 2.1 潜在路径表示

- 特征提取器 \(f_\theta\) 将输入时间序列映射为潜在时间路径：
  \[
  Z_\theta(x) = (z_1, \dots, z_T), \quad z_t \in \mathbb{R}^d
  \]
- 为保留时间顺序和局部动态，构造增强路径：
  \[
  A_\theta(x)_t = \left[ \frac{t}{T}, z_t, \Delta z_t \right], \quad \Delta z_t = z_t - z_{t-1}
  \]
- 对于输出单向量的骨干网络，CPDA 退化为一步路径，但仍保持类条件分布对齐的含义。

### 2.2 签名–谱路径特征

CPDA 从潜在路径中构造四种互补表示：

- **池化特征** \(\psi_{\text{pool}}\)：时间平均语义向量。
- **路径特征** \(\psi_{\text{path}}\)：展平的增强路径，保留时间顺序。
- **谱特征** \(\psi_{\text{spec}}\)：沿时间轴做离散傅里叶变换后取 \(\log(1+|F_t[Z]|^2)\)，捕获周期和振荡结构。
- **低秩路径签名特征** \(\psi_{\text{sig}}\)：
  - 固定随机投影矩阵 \(P\) 将路径增量映射到低维；
  - 一阶签名 \(S_1 = \sum_t u_t\)；
  - 二阶有序交叉增量 \(S_2 = \sum_{i<j} u_i \otimes u_j\)；
  - 组合为 \(\psi_{\text{sig}} = [S_1, \operatorname{vec}(S_2)]\)。

### 2.3 复合签名–谱核

- 对每种表示 \(a \in \{\text{pool}, \text{path}, \text{spec}, \text{sig}\}\) 使用多带宽高斯核：
  \[
  k_a(x,x') = \frac{1}{M}\sum_{m=1}^M \exp\left(-\frac{\|\psi_a(x)-\psi_a(x')\|_2^2}{\sigma_{a,m}^2}\right)
  \]
- 复合核为非负加权和：
  \[
  k_{\text{CPDA}} = \alpha_{\text{sig}}k_{\text{sig}} + \alpha_{\text{spec}}k_{\text{spec}} + \alpha_{\text{path}}k_{\text{path}} + \alpha_{\text{pool}}k_{\text{pool}}
  \]

### 2.4 类条件 MMD 差异

- 源域类别权重来自真实标签：\(w^s_{i,c} = \mathbb{1}[y_i^s = c]\)。
- 目标域权重来自分类器软伪标签：\(w^t_{j,c} = q_{\theta,\phi}(c|x_j^t)\)。
- 归一化后计算每个类别的源、目标核均值嵌入 \(\hat{\mu}_{s,c},\hat{\mu}_{t,c}\)。
- 类条件差异定义为：
  \[
  \hat{D}_{\text{CPDA}}^2 = \sum_{c=1}^K \hat{\pi}_t(c)\ \widehat{\text{MMD}}_c^2
  \]
  其中 \(\hat{\pi}_t(c)\) 为目标类先验估计。

### 2.5 训练目标

\[
\mathcal{L}_{\text{CPDA}} = \mathcal{L}_{\text{cls}} + \lambda \hat{D}_{\text{CPDA}}^2 + \eta \mathcal{L}_{\text{IM}} + \gamma \mathcal{L}_{\text{VAT}}
\]

- \(\mathcal{L}_{\text{cls}}\)：源域交叉熵。
- \(\mathcal{L}_{\text{IM}}\)：目标信息最大化，鼓励置信且避免类别坍缩。
- \(\mathcal{L}_{\text{VAT}}\)：虚拟对抗训练，用于稳定目标伪标签对齐。

### 2.6 理论分析

- 证明 \(k_{\text{CPDA}}\) 是正半定核，CPDA 是积分概率度量。
- 给出类条件目标风险界：
  \[
  R_t(h) \le R_s^{\pi_t}(h) + B \sum_{c=1}^K \pi_t(c)\,\text{MMD}_{\text{CPDA}}(P_c^s, P_c^t)
  \]
- 分析伪标签误差对目标风险的影响。
- 证明 MMD、均值匹配、CORAL、HoMM、DAN 等可视为 CPDA 的受限或退化特例。

## 6. 主要结论与发现

- CPDA 在结构化时间序列和轨迹类数据上表现突出：
  - HHAR：CNN 和 TCN 最优；
  - uWave：三种骨干均最优；

- 结果支持核心动机：**当判别信息编码在时间演化而非仅边缘统计中时，类条件潜在路径对齐特别有效**。
- 理论表明目标误差受源风险和 CPDA 类条件差异控制。

## 7. 优点

- **非对抗、稳定**：无需域判别器，训练更稳定。
- **类条件对齐**：避免不同类别之间的错误匹配。
- **复合核设计**：同时捕获语义、时间顺序、频域和路径签名动态。
- **理论可解释性**：给出核有效性、目标风险界、伪标签误差影响，并将 MMD、CORAL、DAN、HoMM 统一为特例。
- **大规模基准评估**：13 个数据集、3 种骨干、约 30 个基线，设置较全面。
- **受控实验**：用正弦–余弦噪声数据系统分析鲁棒性。

## 8. 不足与局限

- **性能不稳定**：在 Finger Movements、Gestures Mid Air、OnHW 等小样本或高度异质数据集上，CPDA 明显弱于若干基线。
- **对骨干敏感**：CPDA 优点主要在 TCN 和部分 CNN 场景中体现；ResNet18 上经常不占优，甚至明显落后于 CoDATS 等。
- **伪标签依赖**：目标软伪标签误差会直接传播到类条件权值；当目标预测不可靠时，方法可能失效。
- **计算复杂度**：签名和谱特征带来额外计算成本，虽然论文声称可比标准小批量 MMD，但实际复杂度和训练时间未充分量化。
