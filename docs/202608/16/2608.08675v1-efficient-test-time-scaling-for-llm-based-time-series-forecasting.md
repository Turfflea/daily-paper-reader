## 摘要
长期时间序列预测受益于保留趋势和季节性等全局结构。最近基于LLM的预测器通常通过测试时扩展（例如迭代细化）来提高准确性，但这些方法计算成本高昂，并且随着预测时域延长，越来越容易出现全局形状不匹配。我们提出了SCALER，一个从粗到细的预测框架，它首先采用一个为长期形状建模量身定制的轻量级Transformer来预测未来动态的粗略表示。然后，这个预测的形状作为一个紧凑的指导，使LLM能够通过迭代的从粗到细的残差token细化来执行测试时扩展，同时在每一步处理显著更少的token。通过用显式的未来形状预测来指导细化，SCALER减少了对长描述提示的依赖，并且其固定步数细化避免了昂贵的基于奖励模型的选择，进一步降低了计算开销。实验结果表明，SCALER在长期、短期和零样本预测中优于强预测基线，同时显著降低了与用于时间序列预测的扩展LLM相关的推理成本。代码：https://github.com/xuanmay2701/SCALER。

## Abstract
Long-term time series forecasting benefits from preserving global structure such as trends and seasonality. Recent LLM-based forecasters often improve accuracy through test-time scaling (e.g., iterative refinement), but these methods are computationally expensive and increasingly prone to global-shape mismatch as the prediction horizon extends. We propose SCALER, a coarse-to-fine forecasting framework that first employs a lightweight Transformer tailored to long-term shape modeling to predict a coarse representation of future dynamics. This predicted shape then serves as a compact guide for an LLM to perform test-time scaling via iterative coarse-to-fine residual token refinement, while processing substantially fewer tokens at each step. By guiding refinement with an explicit future-shape prediction, SCALER reduces reliance on long description prompts, and its fixed-step refinement avoids costly reward-model-based selection, further lowering computational overhead. Experimental results demonstrate that SCALER outperforms strong forecasting baselines in long-term, short-term and zero-shot forecasting while significantly reducing the inference cost associated with scaled LLM for time series forecasting. ## 2. 论文提出的方法论

SCALER 的核心思路是：**先预测一个下采样的“粗形状”作为全局结构锚点，再用冻结的 LLM 逐步细化出更精细的 token 块**。具体流程如下：

### 2.1 整体框架

- **Stage I（粗形状预测）**：
  - 一个轻量级 Transformer **F** 输入历史序列 \(X\)，预测一个下采样的粗粒度未来形状 token \(\hat{S}_1\)。
  - 目标是捕捉未来时域的低频结构（趋势、季节性、状态切换），但分辨率较低、计算成本小。
- **Stage II（固定步长多尺度细化）**：
  - 使用共享编码器 \(\mathcal{E}\) 将历史序列编码为 token 序列 \(Z_I\)。
  - 初始化细化上下文 \(Z_S = [S_1]\)，其中 \(S_1\) 是 Stage I 预测的粗形状 token。
  - 一个预训练 LLM **G** 作为细化器，执行固定的 \(K\) 步从粗到细的残差细化：第 \(k\) 步预测一个更精细尺度的 token 块 \(\hat{S}_k\)，并将其追加到上下文 \(Z_S\)。
  - 最终通过解码器 \(\mathcal{D}\) 将最细尺度 token 解码为完整分辨率预测 \(\hat{Y}\)。

### 2.2 关键模块

- **多尺度 Patch 编码**：
  - 将多元序列按 patch 切分，编码为与 LLM 嵌入空间对齐的 token。
  - 使用 **prototype-based cross-attention**：先对 LLM 词嵌入矩阵 \(W\) 做线性投影得到原型集合 \(P\)，再将每个 patch 的 query 与原型做 cross-attention，得到 token 表示。
  - 该共享编码器用于历史序列和各尺度目标，确保 token 处于同一表示空间，稳定训练。
- **下采样算子**：
  - 对每个尺度 \(k\)，先对目标序列做归一化，再通过插值下采样到目标分辨率。
  - 尺度调度 \(\{\text{Scale}_k\}_{k=1}^K\) 从粗到细，默认使用 \(T/8, T/4, T/2, T\)，其中 \(T\) 为预测长度。
- **训练目标**：
  - **形状损失** \(\mathcal{L}_{\text{shape}} = \|\hat{S}_1 - S_1\|_2^2\)（Stage I 回归粗形状）。
  - **细化损失** \(\mathcal{L}_{\text{refine}} = \sum_{k=1}^K \|\hat{S}_k - S_k\|_2^2\)（尺度级 token 对齐）。
  - **时间序列重建损失** \(\mathcal{L}_{\text{ts}} = \|\hat{Y} - Y\|_2^2\)（原始分辨率 MSE）。
  - 总损失 \(\mathcal{L} = \mathcal{L}_{\text{shape}} + \lambda \mathcal{L}_{\text{refine}} + \beta \mathcal{L}_{\text{ts}}\)，默认 \(\lambda=\beta=1\)。
- **推理策略**：
  - 固定步数，无候选生成、无奖励模型选择，因此推理开销可预测且较低。
