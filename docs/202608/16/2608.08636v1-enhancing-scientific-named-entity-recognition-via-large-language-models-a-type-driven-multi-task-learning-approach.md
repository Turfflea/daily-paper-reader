## 摘要
科学命名实体识别（SciNER）在科学文本的信息抽取和知识发现中发挥着关键作用。近年来，大语言模型（LLMs）已展现出以极少的人工投入实现有竞争力的 SciNER 性能的能力。现有研究强调了纳入候选实体类型信息对于 LLM 准确识别和分类实体的重要性。然而，当提示中提供了过多的候选实体类型时，LLM 在科学文本中难以准确识别和标注实体，而科学文本中的实体类型比通用领域更为复杂。为应对这一挑战，我们提出了 TdSciNER，一种类型驱动的方法，能够有效利用实体类型信息来增强 SciNER 性能。在 TdSciNER 中，我们首先设计了一个实体类型过滤模型，用于识别给定句子中最可能出现的实体类型。随后，我们在多任务学习框架中引入了一个辅助的多类别实体类型标注任务，与 SciNER 一起训练，以获得更丰富的上下文表示。然后，我们设计了一种基于句子相似度和实体类型多样性的新颖示例选择策略，以激活 LLM 的上下文学习能力，从而提高在不同科学领域的实体识别准确率。在三个数据集上的实验表明，我们的方法取得了与全监督模型相当的性能。进一步分析验证了 TdSciNER 中每个实体类型驱动组件都对 SciNER 性能的提升有所贡献。这项工作为 SciNER 的未来发展以及科学文本挖掘中更广泛的信息抽取任务提供了有价值的见解。

## Abstract
Scientific named entity recognition (SciNER) plays a crucial role in information extraction and knowledge discovery from scientific texts. Recently, large language models (LLMs) have demonstrated the capacity to achieve competitive SciNER performance with minimal human effort. Existing research highlights the importance of incorporating candidate entity type information for accurate entity recognition and classification by LLMs. However, when too many candidate entity types are provided in the prompt, LLMs struggle to accurately recognize and label entities in scientific texts, where entity types are more complex than in general domains. To address this challenge, we propose TdSciNER, a type-driven approach that effectively leverages entity type information to enhance SciNER performance. In TdSciNER, we first design an entity type filter model to identify the most likely entity types present in a given sentence. Subsequently, we introduce an auxiliary multi-class entity typing task within a multi-task learning framework alongside SciNER to obtain richer contextual representations. Then, we develop a novel demonstration selection strategy based on sentence similarity and entity type diversity to activate the in-context learning capabilities of LLMs, thereby improving entity recognition accuracy across diverse scientific domains. Experiments on three datasets demonstrate that our method achieves performance comparable to fully supervised models. Further analysis validates that each entity type-driven component in TdSciNER contributes to the improvement of SciNER performance. This work provides valuable insights for future advancements in SciNER and broader information extraction tasks in scientific text mining.

- **整体含义**：提出类型驱动的多任务学习方法 TdSciNER，通过实体类型过滤、辅助实体分型任务和类型感知的示例选择，提升 LLM 在多个科学领域上的 SciNER 性能，达到与全监督模型相当的水平。

## 2. 论文提出的方法论

- **核心思想**：TdSciNER 以实体类型信息为主线，构建三个协同组件：实体类型过滤模型、辅助实体类型标注任务、以及基于相似度与多样性的演示选择策略。
- **实体类型过滤模型（Entity Type Filter, ETF）**：
  - 使用 GPT-4 为每个实体类型生成领域相关的描述文本，并构造每个类型对应的句子示例集。
  - 采用 BERT 类编码器对输入句子、类型描述和类型示例句分别编码，通过余弦相似度计算输入句子与每个候选类型的匹配分数。
  - 最终相似度分数为描述相似度与示例句相似度的加权和：  
    `f_filter = w · f(h_x, d_c) + (1 − w) · f(h_x, S_c)`。
  - 通过阈值 δ 筛选出最可能出现在句子中的实体类型子集，减少提示中的无关候选类型。
  - 使用对比学习损失对 BERT 类编码器进行微调，使正类型得分高于负类型。
- **辅助实体类型标注任务（Multi-task Learning, MTL）**：
  - 在 SciNER 主任务之外引入辅助多分类任务：给定输入文本及其中的已标注实体，要求模型为每个实体分配候选类型标签。
  - 该辅助任务复用原始 SciNER 标注，无需额外人工标注。
  - 总损失为主任务负对数似然损失与辅助任务交叉熵损失的加权和：  
    `Loss = Loss_SciNER + λ · Loss_EntityTyping`。
- **基于上下文学习的演示选择（ICL demonstration selection）**：
  - 从训练集中随机抽取中等长度句子作为候选示例池。
  - 对每个候选示例计算三项指标：与输入句子的余弦相似度 `Sim`、实体类型多样性 `div_type`、句法结构多样性 `div_structure`（基于句法树的树编辑距离 TED）。
  - 综合得分：  
    `ICL_topk = α·Sim + β·div_type + γ·div_structure`。
  - 按综合得分降序选取 top-k 示例作为 few-shot demonstrations，激活 LLM 的上下文学习能力。

## 6. 主要结论与发现

- TdSciNER 在 SciERC 和 JNLPBA 上取得最高 F1，分别为 **70.58%** 和 **79.34%**；在 BC5CDR 上取得 **89.83%**，与强监督 baseline 接近。
- 与 GPT-3.5-turbo、GPT-4、P-ICL、UniNER 等 LLM-based 方法相比，TdSciNER 显著更优；即使 3B 版本也超过 7B 的 UniNER。
- **实体类型过滤模块**是重要组件：移除后 F1 在 SciERC 下降 2.26%、JNLPBA 下降 2.81%、BC5CDR 下降 0.41%。
- **辅助实体类型任务**对多类型数据集（SciERC、JNLPBA）帮助更大；对仅两类实体的 BC5CDR 增益较小。
- **基于相似度+多样性的演示选择**优于随机或单一策略；在实体类型更多的数据集上，ICL 的贡献更明显。
- 阈值 δ 的最优值与数据集实体类型数量和分布相关；通用默认值约 0.65。
- 计算复杂度方面，TdSciNER 相比 GPT/P-ICL 等引入训练成本，但获得大幅 F1 提升，推理时间并未显著增加。
